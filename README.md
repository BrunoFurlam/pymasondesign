# pymasondesign

Core em Python para dimensionamento e verificação de estruturas em Alvenaria Estrutural (ABNT NBR 16868).

## Estrutura do Pacote

- `pymasondesign.materials`: Materiais (blocos, argamassa, graute, aço).
- `pymasondesign.prisms`: Resistência de prismas (simples e grauteados).
- `pymasondesign.elements`: Elementos estruturais (paredes, esbeltez, excentricidades).
- `pymasondesign.nbr16868`: Coeficientes de segurança e verificações de resistência.
- `pymasondesign.utils`: Utilitários e conversões de unidades.
